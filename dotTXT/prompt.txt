If you're doing this from **VS Code**, it's very simple.

### 1. Open your project

Open your `projectBiddingPlatform` backend folder in VS Code.

You want the folder that contains `requirements.txt`.

For example:

```text
projectBiddingPlatform/
├── requirements.txt
├── main.py
├── ...
```

### 2. Create `runtime.txt`

In VS Code's Explorer:

**Right-click `projectBiddingPlatform` → New File**

Name it exactly:

```text
runtime.txt
```

⚠️ Make sure it is **not** `runtime.txt.txt`.

### 3. Put this inside it

Open `runtime.txt` and write exactly:

```text
python-3.12.11
```

That's the entire file. Don't add quotes or backticks.

Your project should now look like:

```text
projectBiddingPlatform/
├── runtime.txt
├── requirements.txt
├── main.py
├── ...
```

### 4. Save it

`Ctrl + S`

### 5. Push it to GitHub

Open the VS Code terminal:

```bash
git add runtime.txt
git commit -m "Pin Python 3.12 for Render"
git push origin main
```

### 6. Render will redeploy

Because your Render service is connected to your GitHub repository, the new commit should trigger a deployment.

In the Render logs, **look for**:

```text
==> Using Python version 3.12.11
```

instead of:

```text
==> Using Python version 3.14.3
```

Then `pydantic-core` should install without the Rust compilation problem you encountered.

If Render **still says `Using Python version 3.14.3`**, don't change anything else yet—send me the new Render log and I'll tell you exactly what setting is overriding `runtime.txt`.

You can check these next

* Verify Render is using Python 3.12
* Check the correct Render start command
