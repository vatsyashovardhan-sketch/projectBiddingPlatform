The `OPTIONS /listings → 400` in your Render logs means your FastAPI CORS configuration needs to allow the Vercel origin.

### 1. Find your CORS code

In your backend, search:

```text
CORSMiddleware
```

You'll probably have something similar to:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 2. Add your Vercel URL

Change it to:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://localhost:5174",
        "https://codexchange-platform.vercel.app",
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**Important:** don't put a `/` at the end:

```text
https://codexchange-platform.vercel.app
```

not:

```text
https://codexchange-platform.vercel.app/
```

### 3. Push the change

```bash
git add .
git commit -m "fix: allow Vercel frontend in CORS"
git push origin main
```

Render should automatically deploy the new commit.
